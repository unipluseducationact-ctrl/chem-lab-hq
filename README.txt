Chem Lab HQ
HKDSE Chemistry · Topic 01 · S3 lab apparatus

This is a normal website folder. No app store. No login. No internet needed
after you have the files.

HOW TO OPEN
1. Unzip the folder if it is still a .zip.
2. Double-click index.html
   Chrome, Edge, or the smartboard browser all work.
3. If pictures do not load, extract the zip fully first.
   Do not run the site from inside a closed zip window.

HOW TO SHARE WITH OTHER TEACHERS
On this computer, double-click SHARE.bat. That puts Chem-Lab-HQ.zip
on your Desktop. Email or AirDrop that zip.

Whoever receives it: unzip, open the Chem-Lab-HQ folder, then
double-click index.html (or Open-Lab.bat on Windows).

These files must stay together:

  index.html
  app.js
  data.js
  styles.css
  images\
  README.txt
  Open-Lab.bat          (optional, Windows)
  Topic01-Lab-Apparatus-classroom.pptx   (classroom deck — click to reveal)

CLASS KEYS
  1 2 3 4   pick a choice
  Click stations in the top bar to move around.
